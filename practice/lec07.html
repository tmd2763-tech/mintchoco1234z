개인 이력서 웹사이트

앞선 실습의 문서 구조, 링크, 목록, 표와 CSS를 하나의 웹사이트에 적용합니다. 이번 결과물은 활동명과 소개, 실적 표, 수강 과목, 주차별 실습, 수정일을 포함하는 이력서입니다.

이력서 결과물 열기 ↗

문서 구조 설계

  1. header: 활동명·소속·한 줄 소개·GitHub 링크
  2. main 안의 section: 실적 표, 수강 과목 목록, 주차별 실습
  3. footer: 최종 수정일과 맨 위로 이동
<header>소개와 연락 채널</header>
<main>
  <section>실적 표</section>
  <section>수강 과목</section>
  <section>주차별 링크</section>
</main>
<footer>최종 수정일</footer>

앞선 학습 내용 적용

  • 2주차: 실적은 table, 수강 과목은 ul로 표현
  • 3주차: 상대경로로 실습 페이지와 이미지·영상 연결
  • 4주차: 외부 styles.css에서 색상·글꼴·여백 관리
  • 5주차: 화면 너비에 따라 배치가 바뀌는 실습 목록 구성
  • 6주차: 별도 도서 입력 폼 페이지를 사이트에서 연결

화면 확인 순서

  1. PC 첫 화면에 활동명·소속·소개가 보이는지 확인합니다.
  2. 수강 과목의 본 과목 링크를 눌러 주차별 실습으로 이동합니다.
  3. 각 실습 링크를 열고, 예정 항목에는 링크가 없는지 확인합니다.
  4. 좁은 화면에서 목록이 재배치되고 표 내부를 가로로 볼 수 있는지 확인합니다.

실적 표에는 현재 프로젝트와 군 복무·고등학교 활동을 최신순으로 기록했습니다. 제출 전에는 각 내용과 본인 역할이 사실과 일치하는지 직접 확인합니다.
