CSS 적용 연습

다음 영역은 강의의 가상 캠페인 예제를 재현한 것으로, 작성자의 실제 봉사·후원 실적이 아닙니다.

온순이의 하루

안녕하세요. “노즈워크 채널”입니다.

저희는 유기동물과의 동행 캠페인으로 주변에서 흔히 보이는 유기동물에게 간식과 영양제를 후원하는 캠페인을 진행하고 있습니다.

#길고양이 #길냥이

  1. 대학가 주변에 버려진 유기동물이 많은 것을 아시나요?
  2. 노즈워크는 거리의 아이들과 함께 동행하며 정기적으로 영양을 제공하고 후원합니다.
  3. 유기동물과의 동행 <노즈워크>

외부 CSS로 표현 분리

제목은 h3, 본문은 p, 목록 표시는 대문자 알파벳입니다. 예제 링크는 방문 전 초록색, 방문 후 검정색입니다.

.cat-exercise a:link { color: green; }
.cat-exercise a:visited { color: black; }
.cat-exercise ol { list-style-type: upper-alpha; }
