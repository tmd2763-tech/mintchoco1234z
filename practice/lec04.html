외부 CSS로 표현 분리

제목은 h3, 본문은 p, 목록 표시는 대문자 알파벳입니다. 예제 링크는 방문 전 초록색, 방문 후 검정색입니다.

.cat-exercise a:link { color: green; }
.cat-exercise a:visited { color: black; }
.cat-exercise ol { list-style-type: upper-alpha; }
