웹페이지가 열리는 과정

  1. 브라우저가 주소에 해당하는 서버에 요청합니다.
  2. 서버가 HTML과 필요한 파일을 응답합니다.
  3. 브라우저가 HTML 구조와 CSS를 해석해 화면을 표시합니다.
HTML
내용과 문서 구조를 표현하는 마크업 언어입니다.
CSS
색상, 글꼴, 여백과 배치를 지정합니다.
URL
웹에서 자원의 위치를 나타내는 주소입니다.
